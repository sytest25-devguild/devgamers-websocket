# Devgamers Websocket 

## 📣 Info
- 🖥️ [Deployed URL](https://devgamers-websocket.onrender.com)  

## 🏝️ Configure environment variables  
1. Create a file named `.env` in `project root`. 
2. Copy the contents of [.env.example](.env.example) and paste in `.env`.  

## 🏃 Run the app 
- Run 🖥️ `npm run dev`     

## Deploy the app  
- ❕ Replace `1.0.0` with the actual version  
- 🖥️ `git tag api/v1.0.0`  
    - ❕ Create a git tag locally  
- 🖥️ `git push origin api/v1.0.0`  
    - ❕ Push the tag to remote repo    
- ❕ This triggers a workflow using GitHub Actions
